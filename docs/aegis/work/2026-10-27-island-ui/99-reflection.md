# 海島 UI 互動追蹤回顧

本輪以既有呈現 owner 完成左側公開計分欄、可收合／固定的雙列手牌、中央權威骰子與角落成功通知。規則、協定、私人投影、命令確認與工具草稿仍由原有元件／controller 負責。

獨立程式審查與瀏覽器命中測試補足了單元測試看不到的問題：動畫面板必須依事件序號重建；確認面板／聊天工具必須高於手牌；手機手牌需避讓收合計分欄；短橫屏通知寬度必須受右側欄限制。每項都在修正後重新取得證據，沒有把失敗算入通過。

最終 `pnpm verify` 通過 324 tests、11 個既有 DB skips、13/13 smoke；真實三人 Chromium 144 checks，密集六席 Chromium 190/190 checks，兩者皆零瀏覽器例外。完整可重跑命令、截圖與已覆蓋／未覆蓋範圍由 [驗證證據](90-evidence.md) 維護。

複雜度維持 within-budget：一份新互動樣式沿用 table layer，沒有第二套 UI 狀態權威；舊壓縮樣式仍服務未變動結構，全面整理留給獨立樣式維護工作。實機觸控、Safari／Firefox、AT 與完整 WCAG 仍未涵蓋。使用者既有三張截圖保持不動，測試資料庫未重設；無 remote，因此只做本地提交。
