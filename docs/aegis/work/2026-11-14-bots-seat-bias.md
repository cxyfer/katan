# New Shores 座位勝率偏差與 standard 對 naive 勝率拆解（#174、#135）：量測報告

本檔是諮詢性的工作紀錄，只量測、不改任何 bot 決策或規則。對應 issue：[#174](https://github.com/cxyfer/katan/issues/174)（3 人 sf-ck 全 standard 的座位勝率偏差）與 [#135](https://github.com/cxyfer/katan/issues/135) 的「對局拆解」項（standard 在 `sf-new-shores-2025` 3–4 人對 naive 未達 Q3 目標）。背景見 [SF+CK 工作紀錄](2026-11-12-bots-seafarers-cities-knights.md)「已知限制」與 [SF 計畫 §6.3](../plans/2026-11-04-bots-seafarers.md)。

## 結論

1. **偏差來自「各座位拿到的開局頂點」，不是回合順序。** 3p／4p New Shores 的地圖固定，bot 的開局又是確定性的（同一策略、同一座位、500 局開局完全相同），所以每個座位的開局品質固定且差距極大。把開局頂點在座位間輪換（拉丁方陣，每格 500 局）後，全 standard 的勝率**跟著開局走，不跟著座位走**：四種組態（sf、sf-ck × 3p、4p）的座位邊際 p = 0.39–0.93（3p）、0.57（4p），開局邊際全部 p < 0.0001，開局勝率從 1.9% 到 67.6%。
2. **回合順序本身的影響很小，只在 easy／naive 出現。** standard 的座位邊際都落在公平份額附近（3p 31.7–35.0%、4p 24.1–26.4%）。easy／naive 有 ±4–6 pp 的座位邊際，最大一格是 sf-ck 3p easy 的 39.6／32.8／27.6%；方向不一致（sf 3p easy 反而是座位 2 最高）。隨機地圖的 隨機地圖的 `ck-2025` 是純回合順序的對照：全 standard 3p／4p 的座位 p = 0.097／0.024，最大差距 10 pp（4p 座位 1 29.8% 對座位 2 20.2%）；全 easy 最大 16 pp（3p 座位 2 24.8% 對座位 3 40.8%，p < 0.0001）。都明顯小於固定地圖開局邊際的 40–60 pp。
3. **這個偏差同時是策略問題：** 每個座位的開局是 bot 的 setup 演算法在固定地圖上貪心選出來的，沒有「對手會拿走什麼」的前瞻，也沒有「兩顆聚落合起來要湊齊 grain／ore」的要求。4p 座位 3 的開局 27／67 完全沒有 grain，不論換到哪個座位都只贏約 1.9%（sf）／5.0%（sf-ck）；反事實實驗把座位 3 換成帶 grain 的開局，勝率從 1.2% 升到 22.2–45.4%。所以結論不是「地圖不公平、記下來就好」，而是**值得開 setup 策略的後續 issue**（見〈建議〉）。
4. **#135 的假說「船／島投資在 3–4 人回本不足」不成立。** 位置平衡（所有座位共用同一組開局、standard 輪過每個座位）時，standard 對 naive 的勝率在 3 人是 42.5%（公平份額 33.3%，3000 局）、4 人是 41.6%（公平份額 25%，3998 局），換成 3 人不平衡的 26.2%、4 人 31.0%，少掉的 11–16 pp 是 standard 自己選的開局輸給 naive 選的開局（standard 的 setup 比 naive 多一項 `islandSetupBonus`，兩者的差別只在這裡）（naive 在 4p 的第一輪頂點是 10–12 點的內陸，standard 全是 8–9 點的沿海）。投入本身有回本：小島加分 2 次以上時勝率 59.3%（3p）／71.4%（4p），不到 2 次時 20.4%／25.4%。要調的是 setup，不是島嶼計畫。
5. **#177（#171 的修正）不改變座位偏差。** 3p 全 standard 的座位勝率在修正前後幾乎相同（sf 19.0／57.2／23.8 → 20.2／55.6／24.2%，sf-ck 65.8／30.2／4.0 → 66.6／27.8／5.6%），拉丁方陣的結論不變；它讓 sf-ck 3p 1 standard vs 2 naive 的 6 局看門狗歸零（494／500 → 500／500）。有一個需要 #177 作者確認的副作用：在 standard 對 naive 的位置平衡 3p 局中，standard 坐在全內陸開局 63／57 時勝率從 72.6% 降到 61.6%（各 500 局），其他開局不變（見〈#171／#177 前後對照〉）。

## 方法

- **工具**：新增 `packages/bots/bench/survey.ts`（啟動器 `survey.mjs`，仿 `run.mjs`）。對局流程與 `bench/run.ts` 完全相同（同一個 `runBotGame`、仿 BotDriver 模式與看門狗、種子 `10000 + 局號`、focus 依局數輪換座位），所以不改任何既有 bench 的輸出；對同一組態，`survey` 的 focus 勝率與 `bench` 一致。
- **每局記錄**（逐座位）：勝負、終局分數、開局頂點與其點數（pips）、付費／免費造船、小島加分、聚落、城市、道路、發展卡、玩家與銀行交易、產出張數、回合數、最長道路／最大騎士團。來源是 `state.stats` 與 rules 事件。
- **統計**：座位勝率附 Wilson 95% 信賴區間；座位均勻性用卡方（自由度 = 人數 − 1）。每格 500 局；沒有做多重比較校正。
- **座位 vs 位置（`--openings`／`--shift`）**：不改 rules，而是在 bot 的聚落決策外包一層，把座位 s 的兩個聚落頂點換成「第 (s + k) % 人數 份開局」（道路與其後策略不變；腳本頂點不合法時退回 bot 自己的選擇並記 `scriptMiss`）。k 取 0..人數−1 共跑 人數 組，每個座位輪過每份開局（拉丁方陣）：座位邊際平均掉開局，只剩回合順序；開局邊際平均掉座位，只剩位置。`--shift 0` 重現基線已驗證：sf 3p 全 standard 500 局的勝者逐局相同、`scriptMiss` 為 0。**不用「rules scratch patch 輪換起始玩家」**：全同策略時，輪換起始玩家只是座位重新標號，分不出位置與順序，腳本開局的分離更直接，也不必動 rules。
- **位置平衡的 standard 對 naive**：同一組腳本開局套在所有座位（standard 輪過每個座位），standard 與 naive 在每個座位上拿到同樣的開局，差異只剩 setup 以外的策略。開局組有兩份：`stdopen`（全 standard 時各座位的開局）與 `naiveopen`（全 naive 時各座位的開局）。
- **地圖固定的證據**：3p／4p 的 `sf-new-shores-2025`、`sf-ck-new-shores-2025` 在種子 10000–10039 的地形與數字完全相同（`newShoresLayout` 對 3、4 人用 `fixedLayout`）；5–6 人的主島是 `pairedLayout` 洗牌的，本報告沒有量測。`ck-2025` 的地圖每局隨機，當作純回合順序的對照組。
- **版本與環境**：基線、位移、位置平衡與反事實在 `885644a`（v0.4.3-rc.1）；3p 的修正後數字在 PR #177 的 head `2c9bd75`（survey 檔案以未提交的拷貝疊上，不 commit 到 #177）。4p 與 `ck-2025` 沿用 `885644a`（#177 說明 4p 不受影響）。大量運算在 Instabox 跑（最多 3 個程序）；原始逐局 jsonl 與腳本在 repo 外的 scratch（不提交）。

重現（在 `packages/bots`；`$P` 是 profile）：

```bash
node bench/survey.mjs 500 --profile $P --players 3 --roles standard            # 全 standard；easy、naive 同理
node bench/survey.mjs 500 --profile $P --players 3 --roles standard:naive      # 1 standard vs 2 naive；standard:easy 同理
node bench/survey.mjs 500 --profile $P --players 3 --roles standard --openings 35/78,76/63,37/57 --shift 1 --jsonl s1.jsonl
node bench/survey.mjs --latin s0.jsonl s1.jsonl s2.jsonl                       # 座位 × 開局矩陣與兩個邊際
node bench/survey.mjs --merge a.jsonl b.jsonl                                  # 合併分片（位移不同則池化）
```

`--from <局號>` 可把 500 局切成分片平行跑。

### 5.3 假說「船／島投資在 3–4 人回本不足」的判斷

**不成立。** 理由：

1. 位置平衡後，standard 對 naive 的勝率比公平份額高 +9 到 +17 pp，所以島嶼與船的整體策略（連同其餘決策）在 3–4 人是回本的；落差來自 setup。

3. 失敗的局集中在「投入不足」（0–1 次小島加分、1–2 艘船），不是「投入太多而虧損」。
